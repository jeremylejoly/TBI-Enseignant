Lecteur de cotes

Ouvre une sauvegarde cahier_de_cotes_AAAA.json du TBI pour consulter les résultats des élèves, depuis n'importe quel ordinateur, tablette ou téléphone. Le fichier est lu sur cet appareil et n'est envoyé nulle part.

Glisse le fichier JSON ici ou choisis-le dans tes fichiers (Google Drive, Téléchargements…).

En rouge : sous la moitié des points A / E : absent ou excusé, non compté dans la moyenne — : aucune cote encodée

Si ton ordinateur plante

  1. Sur n'importe quel appareil, ouvre cette page.
  2. Ouvre le fichier JSON depuis Google Drive (sur téléphone : « Parcourir » puis Drive).
  3. Pour retrouver ton cahier complet sur un nouvel ordinateur, utilise le bouton « Importer » du cahier de cotes dans le TBI avec ce même fichier.
